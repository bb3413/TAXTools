TAXTools Version Information

Current Version Number Is

This file contains the version information for the all the tax analysis tools. Since there is so much shared code between the tools, there is only one version number and one version log for all the tools.

The version number is a 3-part number, but only the first two parts are used in released versions of the tax analysis tools. The first part is the tax year and the second part is incremented each time a new version is released. The third part of the version number is only used in versions of the tools that have not been released. This part is incremented each time a change is made.

If the version number has an at sign (@) appended to it, that version is under development; it is not ready to be used.

    The point of this change is the tools will provide correct tax calculatons while providng the ability to override specific fields. This solves the problem of when should the program calculate a value and when should the user enter the value. It now calculates everthing that it knows how to calculate based on the information from the user. Currently, only the forms and worksheets needed by the current tools are implemented. In theory, if every IRS form were implemented, the tool would be capable of calculating the complete tax return.
